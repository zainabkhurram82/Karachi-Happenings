# 🎉 Karachi Happenings

Discover Music, Food, Tech & Culture events happening in Karachi — all in one place.

Live Demo: https://karachi-happenings.vercel.app

## ✨ Features
- Browse events in Karachi (Clifton, Gulshan, Burns Road, etc.)
- Filter by Category, Area, Date
- Sign Up / Login system
- Add new events (after login)
- Edit existing events
- Beautiful responsive design

## 🔑 Demo Login
- Username: `admin`
- Password: `1234`
- Or create your own account via Sign Up page

## 🛠️ Tech Used
- Python + Flask
- HTML + CSS (Jinja Templates)
- Deployed on Vercel
